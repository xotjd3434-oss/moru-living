# MORU. — Furniture for everyday life

일상에 자연스럽게 스며드는 가구를 소개하는 가상의 라이프스타일 브랜드 웹사이트입니다. 넉넉한 여백, 자연스러운 소재 이미지, 절제된 타이포그래피로 차분한 공간의 분위기를 표현했습니다.

## Project overview

| 항목 | 내용 |
| --- | --- |
| 프로젝트 유형 | 가구 브랜드 웹 퍼블리싱 포트폴리오 |
| 구성 | 메인 페이지 + 상품 상세 4페이지 |
| 기술 | HTML5 · CSS3 · Sass(SCSS) · Vanilla JavaScript |
| 디자인 키워드 | Slow living · Natural material · Minimal |
| 대응 화면 | 데스크톱 · 태블릿 · 모바일 |

## Design direction

- **공간 중심의 시각 구성**: 큰 인테리어 사진과 여백으로 브랜드의 라이프스타일을 전달합니다.
- **일관된 상품 정보**: 네 상품에 같은 상세 템플릿, 폰트, 글자 크기, 정보 순서와 정렬을 사용했습니다.
- **절제된 인터랙션**: 스크롤 등장 효과와 버튼 호버로 콘텐츠 탐색을 돕습니다.
- **간결한 버튼**: 버튼의 화살표와 섹션 상단 영문 소제목을 제거해 콘텐츠에 집중하도록 정리했습니다.
- **브랜드 푸터**: 딥 올리브 배경에 로고와 소개 문구를 좌우로 배치한 간결한 푸터를 구성했습니다.

## Features

- NEW · COLLECTION · JOURNAL 메뉴에서 해당 섹션 시작 위치로 이동
- 화면에 진입하는 콘텐츠를 한 번씩 부드럽게 표시하는 IntersectionObserver 애니메이션
- 버튼, 상품 카드, 링크의 호버 효과와 키보드 포커스 표시
- 모바일 메뉴 및 Escape 키로 메뉴 닫기
- 상세페이지 썸네일 클릭 시 메인 이미지 교체
- 장바구니 담기 완료 표시 후 1.6초 뒤 버튼 문구 복원
- BAG 버튼에서 상품 이미지·상품명·옵션·가격·수량·합계 확인
- 상품별 수량 조절과 삭제, 빈 장바구니 안내
- localStorage를 이용한 브라우저 내 상품별 장바구니 내역 유지
- 담기 완료 시 “장바구니에 담겼습니다.” 알림과 장바구니 바로 보기 제공
- 스크롤 위치에 따라 표시되는 맨 위로 이동 버튼
- 움직임 줄이기 설정(`prefers-reduced-motion`) 지원

## 작업하며 정리한 내용

- 메인과 상세페이지의 공통 스타일을 함께 사용해 글자 크기와 정렬을 맞췄습니다.
- 컬렉션 영역은 큰 색상 패널 대신 사진과 텍스트의 비례, 여백, 두 줄 제목 중심으로 다시 정리했습니다.
- 헤더에서 SHOP 메뉴를 제거하고, 섹션 이동 시 남아 있던 불필요한 상단 여백을 수정했습니다.
- 큰 이미지 1개와 작은 이미지 2개를 배치할 때, 작은 이미지 사이의 간격까지 포함해 양쪽 끝선이 맞도록 수정했습니다.
- 처음에는 장바구니 숫자만 변경했지만, 담긴 상품을 볼 수 있도록 상품별 저장과 내역 창을 추가했습니다.
- 장바구니에 담은 결과를 바로 알 수 있도록 완료 문구와 알림을 표시했습니다.
- 버튼 문구 복원, 수량 변경과 삭제, 새로고침 후 저장 내역 유지를 확인하는 방향으로 코드를 점검했습니다.

## Scope & assets

이 프로젝트는 가상 브랜드의 프런트엔드 포트폴리오입니다. 상품 사양, 가격과 설명은 시연용 설정이며 실제 주문·결제·회원 기능은 연결되어 있지 않습니다. 장바구니는 브라우저에 상품 내역을 저장하는 데모입니다. 서버나 결제 기능은 연결되지 않습니다. 저널의 READ STORY는 실제 아티클 상세와 연결되지 않은 시안 링크입니다.

사진은 원본 프로젝트의 Unsplash 외부 이미지를 활용한 공간 연출 이미지로, 특정 상품의 실물 사진이나 동일 상품의 다른 각도를 보증하지 않습니다. 이미지와 웹폰트 로딩에는 인터넷 연결이 필요합니다.

사용 폰트: Manrope · DM Sans · Pretendard. 외부 이미지와 폰트를 다른 목적으로 재사용할 때에는 각 제공처의 이용 조건을 확인해 주세요.
